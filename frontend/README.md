# Example


## 🚀 Tech Stack
- **Frontend:** React (Vite)
- **Backend:** Node.js, Express
- **AI Model:** `facebook/bart-large-mnli` via Hugging Face Inference API
- **Tooling:** Cors, Dotenv

## 🛠 การติดตั้งและใช้งาน

### 1. ตั้งค่า Environment Variables
สร้างไฟล์ `.env` ในโฟลเดอร์ `backend/` แล้วใส่ค่า Token ของคุณ:
```text
HF_TOKEN=your_huggingface_token_here
